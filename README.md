# Imperial Blue Website Clone

A front-end clone of the Imperial Blue website built using **HTML**. This project was created as part of my web development learning journey to practice website structure, layout design, and semantic HTML.

## 🚀 Overview

The goal of this project was to recreate the look and feel of the Imperial Blue website while improving my understanding of HTML and how real-world websites are structured.

## 🛠️ Built With

- HTML5

## ✨ Features

- Responsive page structure
- Navigation bar
- Hero section
- Multiple content sections
- Image integration
- Footer section
- Clean and organized code

## 📚 Learning Outcomes

Through this project, I learned:

- Semantic HTML elements
- Website layout structuring
- Content organization
- Navigation design
- Best practices for writing clean HTML

## 🎯 Purpose

This project was developed for educational purposes to enhance my front-end development skills and gain hands-on experience by recreating an existing website design.
